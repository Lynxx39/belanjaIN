## 📖 Tentang Aplikasi

**belanjaIN** adalah aplikasi e-commerce modern dengan pengalaman belanja interaktif yang memadukan estetika *glassmorphism*, performa kilat, dan kemudahan navigasi *mobile-first*. 

Aplikasi ini menghadirkan fitur-fitur belanja lengkap ala e-commerce papan atas:
- ⚡ **Flash Sale Kilat**: Live countdown timer real-time ($HH:MM:SS$) dengan progress bar stok terjual dan badge diskon hingga 60%+.
- 🎨 **Custom 3D Illustrated Icons**: Icon bergaya 3D berkualitas tinggi khas Shopee (Flash Sale, Gratis Ongkir, Mall, Live, Voucher, Koin, belanjaPay, Pulsa) tanpa icon vector generic biasa.
- 🔍 **Pencarian Cerdas & Kategori**: Live search debounce dengan tag saran pencarian dan filter kategori (Gadget, Gaming, Fashion, Skincare, dll.).
- 📱 **Mobile-First & Bottom Navigation**: 2-column responsive layout di perangkat mobile dengan navigasi bawah tetap (*fixed bottom bar*).
- 🌓 **Dual Theme (Dark & Light Mode)**: Dukungan tema gelap obsidian dan tema terang dengan transisi mulus dan penyimpanan preferensi lokal.
- 🛒 **Keranjang Belanja & Promo Voucher**: Sistem kupon diskon (`HEMAT50`, `GRATISONGKIR`, `BELANJABARU`, `CASHBACK20`) dengan kalkulasi potongan harga otomatis.
- 💳 **Simulasi Checkout & Pembayaran**: Pilihan kurir (*Instant, Reguler, Hemat*), metode pembayaran (*ShopeePay, QRIS, Transfer VA, COD*), efek selebrasi *confetti*, dan invoice pelacakan status pesanan.
- 🔴 **belanjaIN Live & Chat Assistant 24/7**: Preview siaran belanja langsung dan simulasi bantuan chat penjual pintar.

### Apa itu Vibe Coding dalam proyek ini?
Melalui pendekatan *vibe coding*, saya berfokus pada:
1. **Desain & Pengalaman Pengguna (UX/UI)**: Mengarahkan visi arsitektur, estetika visual, tata letak mobile, perombakan icon 3D, hingga mikro-interaksi tanpa terjebak boilerplate yang membosankan.

## 🛠️ Teknologi yang Digunakan

- **Frontend Framework**: [React 19](https://react.dev/)

## 💻 Cara Menjalankan di Lokal

1. **Clone repositori**:
   ```bash
   git clone https://github.com/Lynxx39/belanjaIN.git
   cd belanjaIN
   ```

2. **Install dependensi**:
   ```bash
   npm install
   ```

3. **Jalankan server pengembangan**:
   ```bash
   npm run dev
   ```
   Buka `http://localhost:5173/` di browser Anda.

4. **Build untuk produksi**:
   ```bash
   npm run build
   ```

## 🌐 Deployment (GitHub Pages)

Website ini dikonfigurasi untuk ter-deploy secara otomatis melalui GitHub Actions:
1. Masuk ke **Settings** $\to$ **Pages** di repositori ini.
2. Pilih **Source**: `GitHub Actions`.
3. Website akan otomatis di-publish di `https://Lynxx39.github.io/belanjaIN/`.
